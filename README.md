# MONAMI 153 Rebuilt

이번 버전은 **전체 페이지 스크린샷을 배경 이미지로 붙이지 않고**
HTML/CSS 구조와 독립 제품 이미지 에셋으로 다시 만든 버전입니다.

## 파일
- index.html
- style.css
- script.js
- assets/

## 반응형
- 480px 이하: 모바일 홈 화면
- 481px 이상: 좌측 브랜드 쇼케이스 + 우측 모바일 앱 프리뷰

## 에셋 원칙
`assets/`에는 독립된 로고/펜 이미지 파일만 사용합니다.
웹/모바일 전체 화면 캡처 이미지는 페이지 안에 삽입하지 않았습니다.
